# Fonts

Self-hosted Latin subsets (variable weight) used by the Shelf design. All three
are licensed under the SIL Open Font License 1.1 and were downloaded from
Google Fonts.

| File                                | Family                            | Source                                    |
| ----------------------------------- | --------------------------------- | ----------------------------------------- |
| `bricolage-grotesque-500-800.woff2` | Bricolage Grotesque (headings)    | https://github.com/ateliertriay/bricolage |
| `mona-sans-400-700.woff2`           | Mona Sans (text)                  | https://github.com/github/mona-sans       |
| `geist-mono-400-600.woff2`          | Geist Mono (handles, NSIDs, code) | https://github.com/vercel/geist-font      |
